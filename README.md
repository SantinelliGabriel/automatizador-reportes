
# automatizador de reportes de ventas

## descripción

proyecto desarrollado en python para procesar datos de ventas,
calcular importes y generar reportes en formato excel.

## tecnologías

- python 3.11
- pandas
- openpyxl
- excel (.xlsx)

## funcionalidades actuales

- procesamiento de datos de ventas.
- cálculo del importe total por producto.
- cálculo de la facturación total.
- exportación del resultado a excel.

## ejecución

1. instalar python.
2. crear un entorno virtual.
3. instalar las dependencias:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. ejecutar el programa:S

   ```powershell
   python main.py
   ```

## estado

versión inicial: genera un reporte a partir de datos de ejemplo.
